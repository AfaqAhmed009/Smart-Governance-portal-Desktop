
# 🏛️ Smart Governance & Decision Support System (SGDSS)

A desktop-based civic governance application developed using **Java Swing** and **Java** to modernize issue reporting and municipal administration. The system enables citizens to report public issues, track their status, participate in polls, and receive notifications. Government officers and administrators can manage issues, monitor SLA deadlines, assign tasks, and access analytics dashboards. The application also integrates AI-powered decision support for priority prediction, duplicate issue detection, and intelligent officer assignment.

# 🏗️ Project Architecture

The project follows a **Four-Layer Architecture** to ensure modularity and maintainability.

* **Presentation Layer** – Java Swing UI
* **Business Logic Layer** – Core Services
* **Data Access Layer** – DAO/Repository
* **Persistence Layer** – Local File Storage

The architecture separates responsibilities and improves scalability while supporting AI-powered decision making. 

---

# ⚙️ The Development Process

The project was designed around a four-layer software architecture with clear separation of concerns. Java Swing was used to build an intuitive desktop interface, while service classes handled authentication, issue management, notifications, and AI-powered decision support. Local file-based persistence was implemented using Java Serialization, and the system was thoroughly tested across all user roles to ensure reliability, security, and performance.
